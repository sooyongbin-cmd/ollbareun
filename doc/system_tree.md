올바른 관리시스템 트리구조

초기화면 : 경비원관리웹앱 / 경비원모바일앱 두개의 버튼

1. 경비원 관리 웹앱 (admin, 좌측 사이드바 Navigation 메뉴형태)
   │
   ├─ 1-1 대시보드
   │     ├─ 상단 : 요약 카드
   │     │ ├─ 전체 인원
   │     │ ├─ 현재 출근 인원
   │     │ └─ 교육 미이수 인원
   │     ├─ 중앙 : 그래프
   │     │ ├─ 일별 출근율 추이 차트
   │     │ └─ 안전교육 이수율 추이 차트
   │     └─ 하단 : 실시간 출근 현황 리스트
   │         ├─ 성명, 현장명, 출근시간, 교육여부, 상태
   │         ├─ 현장별 인원 배치 확인
   │         ├─ 미출근자 근무시간 알림 버튼
   │         └─ 안전교육 미이수자 푸시 알림 버튼
   │
   ├─ 1-2 직원 관리
   │ ├─ 1-2-1 직원명부관리(목록)/등록/수정
   │ ├─ 1-2-2 근태 관리
   │ └─ 1-2-3 근무지 배정 및 관리
   │     ├─ 근무지목록/등록/수정
   │     └─ 근무지배정
   │
   ├─ 1-3 안전교육 관리
   │ ├─ 1-3-1 교육 영상 관리(목록)/등록/수정
   │ └─ 교육 이수율 관리
   │
   ├─ 1-4 권한 관리
   │ ├─ 마스터 관리자
   │ ├─ 중간 관리자
   │ └─ 등급별 접근 제한
   │
   └─ 1-5 리포트 출력 (Excel 추출 화면)
   ├─ 상단필터
   │ └─ 날짜 / 현장 / 직원이름 검색
   ├─ 본문
   │ └─ 근태기록표, 교육이수 자료
   └─ 하단 버튼 : 고용노동부 제출용 엑셀 자동 양식 생성
   
2. 경비원용 모바일 앱 (guard)
   │
   ├─ 2-1. 메인 화면
   │ └─ 출근 / 퇴근 / 안전교육 / 근무지확인 / 개인프로필 버튼
   │
   ├─ 2-2. 출근 화면
   │ ├─ 상단
   │ │ └─ 사용자 인사말 : “안녕하세요. 홍길동님! (오늘의 근무지 : 문현동현장)”
   │ ├─ 중앙
   │ │ └─ 현재 위치 지도 및 GPS 반경 표시
   │ └─ 하단
   │     ├─ 출근하기 버튼 근무지 반경 내에서만 활성화
   │     └─ 반경 밖 비활성화 안내문구 “근무지 반경 100m 이내에서만 출근이 가능합니다.”
   │
   ├─ 2-3. 퇴근 화면
   │ ├─ 중단 : 오늘 근무 요약 “출근시간 : 09:00 / 교육이수 : 완료”
   │ └─ 하단 : [퇴근하기] 버튼
   │
   ├─ 2-4. 안전교육 진행 화면
   │ ├─ 상단
   │ │ └─ [진행중] 오늘의 안전교육 시청
   │ ├─ 중앙
   │ │ └─ 매일 제공되는 교육 영상 시청, 동영상 플레이어
   │ ├─ 기능 제약
   │ │ ├─ 구간 점프 불가
   │ │ └─ 시청 완료 전 이수 완료 버튼 비활성화
   │ └─ 하단
   │     └─ [안전교육 이수 완료] 버튼, 시청 완료 데이터 자동 전송
   │
   ├─ 2-5. 근무지 체크
   │ ├─ 실시간 위치 확인
   │ ├─ QR 코드 기반 현장 도착 인증
   │ └─ 근무 시간 중 간헐적 위치 기록
   │
   └─ 2-6. 개인 프로필
     ├─ 본인 근무 스케줄 확인
     └─ 월별 출석 현황 확인
