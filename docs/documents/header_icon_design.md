# 상단 헤더 아이콘 이미지 제작 및 적용 가이드

이 문서는 모바일 및 PC 상단 헤더에 사용되는 서비스 아이콘(GuardIcon)의 PNG 이미지 제작 규격과 적용 지침을 정리한 문서입니다.

---

## 1. 아이콘 이미지 규격

| 항목 | 규격 | 비고 |
| --- | --- | --- |
| **원본 이미지 해상도** | **`96px × 96px`** | High-DPI (Retina/3x) 최적화 |
| **화면 노출 크기 (CSS)** | **`24px × 24px`** | 헤더 레이아웃 기준 |
| **파일 포맷** | **PNG-24** | 투명 배경 (Alpha Channel 포함) |
| **추천 외곽 여백** | 1~2px Safe Zone | 렌더링 시 가장자리 뭉개짐 방지 |

---

## 2. 모바일 및 PC 공용 사용 지침

- **단일 파일 사용 (`96px × 96px`)**
  - 별도의 PC용/모바일용 이미지를 따로 제작할 필요 없이 **하나의 PNG 파일**로 PC와 모바일 디스플레이 모두 공용 사용합니다.
- **고해상도(Retina/High-DPI) 대응**
  - 모바일 디바이스뿐만 아니라 맥북 Retina, 4K/QHD PC 모니터에서도 선명하게 노출되도록 3배수(`96px`) 원본을 사용합니다.
- **성능 최적화**
  - 96px 크기의 PNG 이미지 용량은 약 2~5KB 수준으로 매우 가벼우므로 네트워크 및 로딩 성능에 영향이 없습니다.

---

## 3. 코드 적용 예시

```tsx
// React / Next.js 구현 예시

  src="/images/guard-icon.png"
  alt="현장 근로자 아이콘"

/>
```
