# 상단 헤더 아이콘 이미지 제작 및 적용 가이드

이 문서는 모바일 및 PC 페이지 내부의 상단 헤더에 사용하는 서비스 아이콘과 브라우저 탭, PWA 설치 아이콘의 제작 및 적용 지침을 정리한 문서입니다.

---

## 1. 기본 제작 규격

| 항목 | 규격 | 비고 |
| --- | --- | --- |
| **마스터 원본** | **SVG** | 정사각형 `viewBox`와 투명 배경 사용 |
| **화면 노출 크기 (CSS)** | **`24px × 24px`** | 헤더 레이아웃 기준 |
| **PWA 파생 파일** | **PNG 192×192, 512×512** | 앱 설치 및 운영체제 아이콘용 |
| **파비콘 파생 파일** | **SVG + ICO/PNG fallback** | 브라우저 탭 호환성 확보 |
| **추천 외곽 여백** | 전체 크기의 약 5% | 작은 크기에서 가장자리 잘림 방지 |

---

## 2. 용도별 파일 형식

| 사용 위치 | 권장 형식 | 적용 파일 |
| --- | --- | --- |
| 페이지 내부 상단 헤더 | SVG | `/guard-icon.svg`, `/manager-icon.svg` |
| 브라우저 탭 파비콘 | SVG + ICO/PNG | `src/app/favicon.ico` 또는 Next.js metadata |
| 근무자 PWA 설치 아이콘 | PNG | `/guard-icon-192.png`, `/guard-icon-512.png` |
| 관리자 PWA 설치 아이콘 | PNG | `/manager-icon-192.png`, `/manager-icon-512.png` |
| Push 알림 및 운영체제 바로가기 | PNG | 용도에 맞는 PNG 파생 파일 |

- SVG를 마스터 원본으로 관리하여 모바일, PC, Retina 및 고해상도 화면에서 동일한 파일을 선명하게 표시합니다.
- 페이지 내부 아이콘은 SVG를 CSS 기준 `24px × 24px`로 표시합니다.
- PWA 설치 아이콘은 플랫폼 호환성을 위해 SVG 원본에서 PNG 192×192 및 512×512 파일을 생성합니다.
- 브라우저 탭 아이콘은 페이지 내부 헤더 아이콘과 표시 위치가 다릅니다. 같은 디자인을 사용할 수 있지만 작은 크기에서도 식별되도록 단순화한 파비콘 파생 파일을 사용합니다.
- 관리자 화면은 `manager-icon`, 근무자 화면은 `guard-icon` 디자인을 사용하여 역할을 구분합니다.

---

## 3. 코드 적용 예시

```tsx
// 현장 근무자 페이지 헤더
<img
  src="/guard-icon.svg"
  alt="현장 근로자 아이콘"
  width={24}
  height={24}
  className="size-6 object-contain"
/>
```

```tsx
// 관리자 페이지 헤더
<img
  src="/manager-icon.svg"
  alt="관리자 아이콘"
  width={24}
  height={24}
  className="size-6 object-contain"
/>
```

## 4. 관리 원칙

1. 아이콘의 도형과 색상 수정은 SVG 마스터 원본에 먼저 반영합니다.
2. SVG 변경 후 PWA용 PNG와 파비콘용 ICO/PNG를 다시 생성합니다.
3. SVG에는 정사각형 `viewBox`, 투명 배경 및 충분한 안전 여백을 유지합니다.
4. 외부에서 전달받은 신뢰할 수 없는 SVG를 검증 없이 인라인으로 삽입하지 않습니다.
5. 변경 후 페이지 헤더, 브라우저 탭, PWA 설치 화면과 Push 알림에서 각각 표시 상태를 확인합니다.
