# 출근 후 교육 미이수 알림 대기시간

- 시스템 설정 `S000001`의 내용은 0 이상의 정수 분 단위다.
- 출근 기록 생성 또는 출근 시간 변경 시 DB 트리거가 해당 값을 읽어 `due_at`을 계산한다.
- 기존 예약은 설정 변경만으로 다시 계산하지 않는다. 출근 취소 처리와 이미 발송한 예약의 중복 방지는 유지한다.
- 설정이 없거나 값이 유효하지 않으면 기존 기본값 30분을 사용한다.
- 현재 Cron 주기와 운영 시간은 유지한다. 설정 시간이 지난 예약은 다음 Cron 실행에서 교육 미이수를 확인하고 처리한다.
- 설정 상세 화면 버튼 순서는 저장, 삭제, 목록이다.

검증: 설정 저장 및 버튼 순서 테스트, `supabase/tests/education_reminder_delay.sql`의 롤백 테스트(설정별 예약 시간, 기본값, 기존 예약 유지, 출근 취소).
