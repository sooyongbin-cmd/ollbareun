# 교육자료 시작일·종료일 및 기타 구분

- 실제 테이블 `education_resources`에 `startdate`, `enddate` DATE 컬럼을 추가한다. 두 컬럼은 필수이며 시작일 <= 종료일 제약을 적용한다.
- 기존 자료의 두 날짜는 사용자 요청 시점의 한국 날짜 `2026-10-07`로 입력한다. 테이블 설명은 교육자료, 컬럼 설명은 시작일·종료일이다.
- 등록·수정 화면은 안전교육구분 우측에 날짜 입력을 배치한다. 두 날짜를 필수 입력받고 서버에서도 실제 날짜와 기간 순서를 검증한다.
- 구분 선택지는 일일·월간·분기·반기·기타이며 수정 화면에서도 변경할 수 있다. 수정 화면의 관리자 화면 문구를 제거한다.
- 교육자료 등록 시 구분별 1건 제한을 제거한다. DB에는 구분별 UNIQUE 제약이 없으므로 기본키와 기존 제목·링크 검증은 유지한다.
- 목록 컬럼은 교육구분·제목·시작일·종료일이고, 구분 순서는 일일·월별·분기·반기·기타이다. 이수현황 컬럼과 관련 목록 API 요청을 제거한다.
- 기타 자료를 읽고 이수 기록에 저장할 수 있도록 교육구분 매핑과 교육자료·이수 테이블의 구분 CHECK 제약을 확장한다.

검증: 날짜 누락·유효성·기간 순서, 등록·수정 API 전달, 구분 중복 등록, 기타 선택·수정, 목록 컬럼·정렬 테스트 및 DB 롤백 테스트.
