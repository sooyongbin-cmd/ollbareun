# 알림 클릭 창 처리

- 알림 클릭 시 시스템 설정 `S000002`를 조회한다. Y는 알림 대상 URL을 새 창으로 연다.
- N은 같은 브라우저 프로필에서 실행 중인 관리자 창을 찾아 앞으로 가져오고, 제목과 본문을 관리자 앱 모달로 전달한다.
- 관리자 앱에서 알림 모달을 확인하면 새 창 처리와 동일한 알림 대상 URL로 이동한다. 이동 대상은 같은 사이트로 제한하고, 대상 화면의 기존 인증·권한 검증을 따른다.
- 관리자 로그인 화면은 재사용하지 않는다. 관리자 창이 없거나 포커스/메시지 수신 확인에 실패하면 알림 대상 URL을 새 창으로 연다.
- 설정 조회는 캐시하지 않으며, 조회 실패 시 기본값 N을 적용한다.
- 여러 알림은 모달에서 순서대로 표시한다. 기존 알림 수신 시 근무자 앱에 전달하는 처리는 유지한다.
- 배포 후 기존 관리자 앱을 새로고침해야 메시지 수신 컴포넌트가 활성화된다.

검증: 서비스워커 이벤트 실행 테스트, 정책 API 테스트, 관리자 모달 수신·순차 표시·리스너 정리 테스트 및 기존 근무자 푸시 등록 테스트.
