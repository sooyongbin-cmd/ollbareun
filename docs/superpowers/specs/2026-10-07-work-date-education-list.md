# 출근날짜별 교육자료 및 이수 목록

- 관리자 근태상세와 근무자 안전교육은 교육자료의 시작일 <= 출근날짜 <= 종료일 조건으로 조회한다. 자료 생성일이 아닌 명시된 적용 기간을 사용한다.
- 구분 순서는 일일·월별·분기·반기·기타이며 같은 구분에서는 제목 순으로 정렬한다.
- 이수 판정은 사용자가 확정한 해당 근무자·출근날짜의 이수 기록 유무를 따른다. 현재 스냅샷 스키마의 교재 제목과 교육구분을 함께 비교한다.
- 관리자 화면은 구분·교육·이수 테이블을 사용한다. 이수는 텍스트, 미이수는 버튼이다. 버튼 클릭 시 별도 근태 저장 없이 즉시 해당 출근날짜로 이수 기록을 저장한다.
- 관리자 전용 API는 근태 ID에서 직원과 출근날짜를 직접 읽고 실제 출근 기록 및 교재 적용 기간을 확인한다. 클라이언트가 제공한 직원·날짜를 신뢰하지 않는다.
- 범위 밖 자료의 이수 요청은 서버에서 거부하고, 기존 이수 행은 다시 생성하지 않는다. 저장 중 중복 클릭을 잠그고 실패하면 미이수 상태를 유지한다.

검증: 날짜 양끝 경계·기간 밖 자료·정렬·다른 근무자와 이전 날짜 기록 제외, 관리자 인증·출근 기록 검증, 버튼 즉시 저장 및 기존 근무자 영상 시청/이수 테스트.
