올바름 인력관리시스템 디자인 가이드 ​

항목내용
문서 유형디자인 가이드

기준 문서요구사항분석서, 기능명세서, 화면명세서

1. 디자인 원칙 ​

  • 업무 정보를 빠르게 찾을 수 있도록 명확하고 일관된 화면을 제공한다.
  • 관리자 화면은 목록·검색·입력 중심으로, 현장 근무자 화면은 한 손 조작이 쉬운 모바일 중심으로 설계한다.
  • 장식보다 정보 위계, 충분한 여백, 읽기 쉬운 대비를 우선한다.
  • 색상만으로 상태를 구분하지 않고 상태명과 안내 문구를 함께 제공한다.
  • PC와 모바일에서 동일한 업무 의미와 용어를 유지한다.

2. 색상 ​

용도기준
Primary주요 버튼, 활성 메뉴, 핵심 강조에 사용
Canvas페이지 기본 배경
Surface카드, 입력 영역, 표 배경
Ink제목과 본문 기본 글자

  • 실제 색상값은 src/app/globals.css의 디자인 토큰을 우선 적용한다.
  • 컴포넌트에 임의 색상을 추가하기보다 공통 토큰을 확장한다.

3. 타이포그래피 ​

  • 기본 글꼴은 Pretendard 계열을 사용한다.
  • 페이지 제목은 32~40px, 섹션 제목은 20~24px, 본문은 15~17px를 권장한다.
  • 입력 라벨과 표 머리글은 본문보다 작게 사용하되 12px 미만으로 축소하지 않는다.
  • 제목, 버튼, 입력 라벨은 동일 화면에서 동일한 굵기 체계를 유지한다.

4. 레이아웃 ​

4.1 관리자 화면 ​

  • PC에서는 좌측 사이드바와 본문 영역을 사용하고, 모바일에서는 햄버거 메뉴로 전환한다.
  • 본문 최대 폭은 업무 화면 특성에 따라 980~1180px를 기준으로 한다.
  • 목록 화면은 제목, 조회 조건, 주요 작업, 결과 목록 순으로 구성한다.

4.2 현장 근무자 화면 ​

  • 세로형 모바일 화면을 우선하며 주요 버튼은 충분한 터치 영역과 전체 폭을 확보한다.
  • 위치·카메라·알림 등 권한이 필요한 기능은 요청 목적과 거부 시 대안을 안내한다.
  • 처리 중에는 로딩 상태를 표시하고 중복 입력을 방지한다.

4.3 회사소개 홈페이지 ​

  • 대표 이미지와 핵심 메시지, 서비스 강점, 사회적 가치, 상담 신청, 회사 정보 순으로 구성한다.
  • 카드 영역은 모바일 1열, 넓은 화면 3열을 기본으로 한다.

6. 접근성 및 반응형 ​

  • 모든 입력 요소에 연결된 라벨을 제공한다.
  • 키보드 포커스를 시각적으로 표시하고 버튼과 링크를 키보드로 실행할 수 있게 한다.
  • 텍스트와 배경은 WCAG AA 수준의 대비를 목표로 한다.
  • 모바일에서 가로 스크롤이 필요한 표는 카드형 전환 또는 안전한 스크롤 영역을 제공한다.
  • 이미지에는 용도를 설명하는 대체 텍스트를 제공한다.

7. 변경 관리 ​

  • 공통 토큰이나 컴포넌트 변경 시 관리자·근무자·회사소개 화면의 영향을 함께 확인한다.
  • 신규 화면은 화면명세서.md에 화면 ID와 동작을 먼저 반영한다.
  • 구현 검수 시 PC, 모바일, 키보드 조작, 권한 거부 상태를 포함한다.
