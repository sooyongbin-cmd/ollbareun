------------------------------------
이름 연락처 퇴직 <- 자료목록창
------------------------

-. 상세 형태 : 1개의 자료에 대해 입력/수정/삭제 기능을 수행한다. ​

화면이름 <- 화면제목
이름 _____ 연락처 _____ [저장] <- 자료내용

-. [신규]버튼을 클릭하면 "1-2-1-1 직원등록" 화면으로 이동. -. 목록에서 이름-연락처를 클릭하면 해당 자료로 "1-2-1-2 직원수정" 화면으로 이동

1-2-1-1 직원등록 ​

직원등록
이름 _____ 연락처 _____ [저장]

-. [저장]버튼을 클릭하면 저장후 처리결과 메시지를 띄우고 "직원명부관리"화면으로 이동

1-2-1-2 직원수정 ​

직원수정
이름 xxx 연락처 xxxxxxxxx 퇴직 _ [저장][삭제]

-. [저장]버튼을 클릭하면 저장후 처리결과 메시지를 띄우고 "직원명부관리"화면으로 이동 -. [삭제]버튼을 클릭하면 확인메시지를 띄우고 처리후 "직원명부관리"화면으로 이동
