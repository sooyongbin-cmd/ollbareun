올바름 인력관리시스템 테스트 계획서 ​

1. 목적 ​

요구사항과 기능명세에 정의된 관리자·현장 근무자·회사소개 기능이 지원 환경에서 정확하고 안전하게 동작하는지 확인한다.

2. 테스트 범위 ​

구분대상
단위 테스트업무 규칙, 입력 검증, GPS 계산, 데이터 변환
컴포넌트 테스트폼, 목록, 모달, 내비게이션, 반응형 상태
API 테스트상태 코드, 요청·응답, 인증, 오류 처리
통합 테스트화면-API-DB 흐름, 외부 연동 실패 처리
빌드 검증TypeScript, ESLint, Next.js production build
사용자 인수 테스트요구사항·기능·화면 명세 기반 주요 업무 시나리오

3. 환경 ​

  • Node.js와 package-lock.json 기준 의존성을 사용한다.
  • 단위·컴포넌트 테스트는 Vitest와 jsdom을 사용한다.
  • DB 통합 검증은 운영과 분리된 Supabase 프로젝트를 사용한다.
  • PC Chrome/Edge와 Android·iOS 모바일 브라우저에서 반응형 동작을 확인한다.

5. 비기능 테스트 ​

  • 모바일 360px 수준부터 데스크톱까지 레이아웃 깨짐을 확인한다.
  • 키보드 포커스, 라벨, 명도 대비, 대체 텍스트를 확인한다.
  • 서비스 역할 키와 비밀값이 클라이언트 번들·로그에 노출되지 않는지 확인한다.
  • 목록과 대시보드의 데이터가 증가해도 사용 가능한 응답 시간을 유지하는지 점검한다.
  • 외부 지도·메일·푸시 장애 시 핵심 저장 데이터와 오류 안내를 확인한다.

6. 실행 명령 ​

bash
npm ci

7. 결함 관리와 종료 기준 ​

  • 결함은 재현 절차, 기대 결과, 실제 결과, 환경, 화면 자료와 함께 기록한다.
  • 개인정보 노출, 인증 우회, 데이터 손실 결함은 최우선으로 처리한다.
  • 핵심 시나리오가 모두 통과하고 중대 결함이 없을 때 배포 가능으로 판단한다.
  • 경미한 결함은 고객과 잔여 위험 및 조치 일정을 합의한다.
